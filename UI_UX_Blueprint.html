UI / UX BLUEPRINT

दूध हिसाब — मॉडर्न UI/UX डिज़ाइन दस्तावेज़

हर स्क्रीन की वायरफ्रेम रूपरेखा, उसके तत्व, और हर बटन दबाने पर क्या होगा (User Flow) — इसी ऐप के हिसाब से।

रंग (Colors)

  • रेडियस: कार्ड 16px, बटन 12px, चिप 20px

  • सेफ़ एरिया (नॉच) का ध्यान: ऊपर/नीचे env(safe-area-inset)

  • 🥛 स्वागत — "दूध हिसाब में स्वागत"

User Flow: ऐप पहली बार खुले → ऑनबोर्डिंग दिखे → "आगे" पर अगली स्लाइड → आख़िरी पर "शुरू करें" दबाएँ → ऑनबोर्डिंग बंद, होम खुले। कहीं भी "छोड़ें" दबाने पर सीधे होम। दोबारा कभी नहीं दिखेगी (याद रखी जाती है)।

2.9 नोटिफिकेशन (🔔)

शीट: 🔔 सूचनाएँ⏳ बकाया याद दिलाएँ · ☁️ बैकअप ले लें · 📦 स्टॉक कम · 🎯 मासिक लक्ष्य · 🔌 Drive जोड़ें
User Flow: 🔔 पर टैप → सूची खुले (badge में गिनती)। किसी सूचना पर टैप → संबंधित स्क्रीन (बकाया / बैकअप / स्टॉक)। सूचनाएँ डेटा से अपने आप बनती हैं। कुछ न हो तो "सब ठीक है!"।

3. कंटेंट राइटिंग व माइक्रोकॉपी

CTA (कॉल टू एक्शन)

"आगे", "शुरू करें", "सेव करें", "अभी बैकअप करें", "Drive से जोड़ें", "सबकी डिफ़ॉल्ट एंट्री" — छोटे, सीधे, क्रिया-शब्द।

एरर व सूचना संदेश (विनम्र)

  • "कम से कम 2 अक्षर लिखें"
  • "मात्रा डालें" · "नाम डालें"
  • "Drive बैकअप नहीं हो सका — दोबारा कोशिश करें"
  • "आप ऑफ़लाइन हैं — डेटा फ़ोन में सेव हो रहा है, नेट आने पर Drive में सिंक होगा"
  • "कोई डेटा नहीं" की जगह ज़्यादा मददगार: "अभी कोई एंट्री नहीं — ➕ से पहली एंट्री जोड़ें"

खाली स्क्रीन (Empty States)

  • एंट्री: 📭 "इस दिन कोई एंट्री नहीं"
  • बकाया: ✅ "कोई बकाया नहीं"
  • नोटिफिकेशन: ✅ "कोई सूचना नहीं — सब ठीक है!"
  • खोज: 🔍 "कुछ नहीं मिला"

4. लीगल व प्राइवेसी (संक्षेप)

🔒 प्राइवेसी पॉलिसी

  • सारा डेटा आपके ही फ़ोन/ब्राउज़र में — कोई हमारा सर्वर नहीं
  • Google साइन-इन पर सिर्फ़ नाम, ईमेल, फ़ोटो
  • Drive बैकअप आपकी खुद की Drive में; ऐप सिर्फ़ अपनी बनाई फ़ाइल पढ़े
  • कोई विज्ञापन नहीं, डेटा किसी को नहीं बेचा जाता
  • "सारा डेटा मिटाएँ" = हमेशा के लिए हटा

📜 नियम व शर्तें

  • ऐप आपके अपने इस्तेमाल के लिए
  • बैकअप नियमित लेते रहें
  • ऐप "जैसा है" (as-is)
  • रकम/बिल/रिपोर्ट अपनी जाँच के बाद भरोसे लायक
  • डेटा कभी भी निर्यात या मिटा सकते हैं

5. ऑनलाइन + ऑफ़लाइन

ऐप PWA है — सर्विस वर्कर के साथ। एक बार खुलने के बाद बिना इंटरनेट भी पूरा चलता है। ऑफ़लाइन होने पर ऊपर पीला बैनर दिखता है; नेट आते ही बदलाव अपने आप Drive में सिंक होते हैं। होम स्क्रीन पर "Install" करके ऐप की तरह इस्तेमाल करें।

6. आगे क्या जोड़ा जा सकता है (Roadmap)

  • जल्दी बिल/इनवॉइस नंबर, स्टाफ अटेंडेंस, महीने-दर-महीने तुलना रिपोर्ट
  • मध्यम Maps (पता/रूट मैप), बिल स्कैन (OCR)
  • बाहरी सेटअप Apple ID लॉगिन (Apple Developer चाहिए), फ़ोन OTP लॉगिन (SMS सेवा चाहिए), AI सहायक (Gemini API key), Push नोटिफिकेशन (Firebase)
